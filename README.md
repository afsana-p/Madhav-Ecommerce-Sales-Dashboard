# Madhav E-commerce Sales Dashboard

An interactive Power BI dashboard that analyses e-commerce sales performance across states, product categories and payment modes.

##  Dashboard Preview
![Dashboard](images/dashboard.png)

## Objective
Help the business see what drives sales and profit, and which states, products and customers perform best.

##  Key Metrics
- Total Amount (Sales)
- Total Profit
- Total Quantity
- Average Order Value (AOV)

## Visuals Included
- Profit by Month (trend)
- Sales by State and Sub-Category
- Profit by Sub-Category
- Category share by Profit and Quantity (donut charts)
- Sales by Payment Mode
- Slicers for State and Order Date
